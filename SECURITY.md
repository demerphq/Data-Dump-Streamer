# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately using
[GitHub's private vulnerability reporting](https://github.com/demerphq/Data-Dump-Streamer/security/advisories/new).
You can also contact the maintainer, Yves Orton, at
[yves@cpan.org](mailto:yves@cpan.org).

Include the affected Data::Dump::Streamer and Perl versions, a minimal
reproducer, the expected and actual behavior, and the potential security
impact. Reports about older releases are welcome even when the current
release appears unaffected.

Please contact the maintainer before opening a public issue or pull
request, publishing an exploit, or issuing a public advisory.

## Coordinated disclosure

Please coordinate the affected versions, fix and disclosure date with the
maintainer. If you are requesting or assigning a CVE, share the identifier
and draft advisory privately as part of that coordination.

Please notify the maintainer even when the issue appears to have already
been fixed in a released version. An existing fix does not replace
notification or confirmation of the vulnerability's scope.
